# ADR-0003: Без Keycloak — zero-trust RBAC в control-plane

- Статус: Accepted
- Дата: 2026-06-01

## Контекст
Нужны роли и zero-trust (DS/DE/MLSecOps/Product/CEO). Keycloak/OIDC тяжёл для окна <1 недели и ноутбучного демо.

## Решение
RBAC реализуем в самом control-plane (сессии/JWT) с **object-level авторизацией** (не только по маршруту).

## Последствия
- (+) быстрее, меньше контейнеров, полный контроль над ролями и видимостью.
- (−) корректность авторизации — на нас; риск CP-3 (IDOR/privesc) смягчаем сценарием ESC-01 и тестами.

## Альтернативы
- Keycloak/OIDC — оверкилл для скоупа.
