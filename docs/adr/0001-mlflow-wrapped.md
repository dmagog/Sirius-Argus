# ADR-0001: MLflow обёрнут, доступен только через control-plane

- Статус: Accepted
- Дата: 2026-06-01

## Контекст
Нужны реестр/трекинг (версии, гиперпараметры, артефакты, lineage). MLflow даёт это «даром», но у него нет RBAC и много CVE.

## Решение
Поднимаем MLflow **только во внутренней docker-сети** (порт наружу не публикуется). Доступ — исключительно через control-plane, который и владеет RBAC и аудитом.

## Последствия
- (+) lineage/версии/гиперпараметры без своей разработки; «нет прямого доступа» = живая демонстрация zero-trust и единой точки входа.
- (−) интеграционная стоимость; CVE MLflow (риски ML-1, ML-2) — смягчаем пином версии, сетевой изоляцией, integrity-проверкой и тем, что только control-plane пишет.

## Альтернативы
- Полностью кастомный трекинг — больше контроля, но дублируем готовое.
- Выставить MLflow напрямую — отклонено (нет RBAC).
