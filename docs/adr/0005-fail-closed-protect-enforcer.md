# ADR-0005: Fail-closed гейты; защищаем контур контроля в первую очередь

- Статус: Accepted
- Дата: 2026-06-01

## Контекст
Приоритизация рисков по L×I ([risk-register.md](../threat-model/risk-register.md)) показала: **все критические риски — в контуре контроля** (control-plane, реестр, CI, сканеры), а не в атаках на модель. Компрометация энфорсера обнуляет все остальные контроли.

## Решение
1. Гейты **fail-closed** по умолчанию: ошибка/недоступность сканера = блок, а не пропуск (риск SC-1). Пропуск гейта — только с правами и записью в аудит.
2. Самозащиту контура (сетевая изоляция: наружу только control-plane и serving-gateway; per-service креды; object-level authz; short-lived токены; hash-chain аудита; скан собственных зависимостей) закладываем уже в **И0/И1**, до «зрелищных» демо атак на модель.

## Последствия
- (+) сначала закрываем самые опасные риски; порядок работ совпадает с картой рисков.
- (−) ранние итерации менее «демо-эффектны» — компенсируем showpiece-сценариями в И2.

## Альтернативы
- Сначала демо атак на модель — оставляет энфорсер уязвимым, все гейты становятся фикцией.
