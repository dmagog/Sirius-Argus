# ADR-0002: Gitea + control-plane как CI = единая точка входа в прод

- Статус: Accepted
- Дата: 2026-06-01

## Контекст
Нужна единая контролируемая точка входа в прод без обходных путей, полностью локально на ноутбуке, без внешних зависимостей.

## Решение
Gitea (локальный git: PR, branch protection, вебхуки) + control-plane выступает CI: webhook PR → гейты `security/` → commit-status обратно → синк findings в реестр. Без внешнего CI и без отдельного раннера.

## Последствия
- (+) self-contained, поднимается одним `docker compose`; демонстрирует «no bypass» (риск GT-1).
- (−) сложность вебхук-интеграции; запасной путь — внутренний промоушен-пайплайн в control-plane.

## Альтернативы
- GitHub Actions — внешняя зависимость, хуже для «одной команды на ноуте».
- Только внутренний пайплайн без git — слабее закрывает «secure git».
