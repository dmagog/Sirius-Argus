# Реестр скриншотов для документации

> План иллюстрации Sirius Argus. Кадры снимаются с живого стека (`localhost:8080`) **без рамок браузера**, инстансы подобраны как самые показательные. Статус: ☐ не снято · ✅ готово (тёмная + светлая + пара).

## Конвенции захвата
- **Метод:** скриншот контента страницы (headless-браузер / Preview MCP) — только вьюпорт/элемент, без хрома браузера (адресной строки, вкладок).
- **Вьюпорт:** 1600×1000, масштаб 2× (чёткий текст). Широкие таблицы — до 1680.
- **Тема:** базовая **тёмная** (SOC-консоль). Дубль в светлой — по необходимости (тумблер в топбаре).
- **Сплэш `/map`:** проигрывается при каждой загрузке (~9с). Чистый кадр карты — после сплэша; кадр самого сплэша — в середине анимации (кольцо-комета + бутлог).
- **Карточки/реестры:** скроллбары прятать; для длинных таблиц брать верх (структура важнее хвоста).
- **Тема и варианты:** на каждый кадр два полноразмерных файла —
  - тёмная: `docs/_assets/img/NN-name.png`
  - светлая: `docs/_assets/img/light/NN-name.png`
- **Раскладка в доках:** отдельные файлы рядом через HTML-таблицу `<table><tr><td>тёмная</td><td>светлая</td></tr></table>` (а не склейку) — так каждая тема по клику открывается в оригинале (зум пиксель-в-пиксель). В README — в раскрывающейся `<details>`-галерее (карусель/JS на GitHub недоступны — разметка санитизируется).
- **Инструмент:** headless Chrome (тёмная) и Playwright на установленном Chrome с инъекцией `localStorage['sa-theme']='light'` (светлая). Ссылки из доков относительные.
