# Sirius Argus — BDD-каталог сценариев

> Каждая угроза = поведение; контроль = ответное поведение системы. Каждый сценарий служит сразу четырём целям: **Модель Угроз**, **acceptance-тест** (pytest-bdd против живой системы), **шаг демо**, **строка карты покрытия**.
>
> Теги: `@<категория>` · `@OWASP-MLxx` / `@ATLAS-<tactic>` · `@P0|P1|P2`. Персоны (A1–A21) — из [personas.md](personas.md); оценка риска — [risk-register.md](risk-register.md). Статус всех сценариев — `spec`.

## Конвенции

- **P0** — обязателен в демо (money-shot). **P1** — низковисящий фрукт. **P2** — practice-maxxing / частично-остаточный.
- Каждый `.feature` = категория; `Scenario` = строка таблицы. `Then`-клаузы — поведение, которое система **обязана отработать**.
- ID сценариев — **две цифры** (`SUP-01`); ID рисков в [risk-register.md](risk-register.md) — **одна цифра** (`SC-1`). Префиксы `DATA`/`SC`/`RB` встречаются и там, и там — различать по числу цифр.

## Сценарии (Gherkin) — контур контроля (новые)

```gherkin
@ci-supply-chain @ATLAS-execution @P0
Feature: Защита CI/build-конвейера
  Scenario: CI-01 — Отравленный шаг пайплайна не проходит
    Given пайплайн использует базовый образ без пина или нестандартный шаг
    When запускается CI на PR
    Then шаг с неподписанным/неприкреплённым образом не выполняется
    And создаётся Finding(type=ci-supply-chain)
    And раннер работает с минимальными правами, без доступа к прод-секретам
```

```gherkin
@availability @ddos @P1
Feature: Устойчивость к распределённому DDoS
  Scenario: DOS-01 — Объёмный флуд не роняет платформу
    Given внешние поверхности (serving-gateway и control-plane) стоят за reverse-proxy
    And заданы global и per-IP rate-limit, лимиты соединений и таймаутов
    When приходит объёмный флуд с множества источников
    Then избыточные запросы отбрасываются быстро (429/503, load-shedding)
    And ядро остаётся доступным для легитимного трафика
    And создаётся Finding(type=ddos) и поднимается алерт
    And объёмная L3/L4-защита (upstream scrubbing) зафиксирована как остаточный риск
```
